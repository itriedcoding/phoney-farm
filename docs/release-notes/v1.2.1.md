# Phone Farm 1.2.1

A desktop launcher fix, and Windows now ships as a single `.exe`.

## Desktop

- **Software rendering by default.** The window no longer depends on Direct3D/OpenGL, so it opens on
  virtual machines, remote-desktop sessions and machines without a usable GPU. Start it with `--gpu`
  to opt into hardware rendering.
- **No silent failures.** If the window cannot open, the agent keeps running and the full reason is
  written to `%USERPROFILE%\.phonefarm\desktop.log`.
- **One download.** `PhoneFarmDesktop-1.2.1.exe` is a proper Windows installer: shortcuts, per-user
  install, its own bundled runtime. There is no zip to unpack any more.
- **About "failed to launch KVM":** that message is produced by Android emulators (QEMU/KVM, HAXM,
  WHPX). Phone Farm Desktop does not use virtualisation and cannot emit it. If you see it, an emulator
  is being started — install the APK on the phone itself, or run `PhoneFarmDesktop.exe` on Windows.

## Phone

- Version bump only: no behavioural changes in the app itself. Live screens, the AI operator, social
  automation, SOCKS5 proxies and device profiles are unchanged from 1.2.0.

## Install

`PhoneFarm-1.2.1.apk` for Android 8.0+, `PhoneFarmDesktop-1.2.1.exe` for 64-bit Windows 10/11.
