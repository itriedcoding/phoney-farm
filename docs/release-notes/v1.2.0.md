# Phone Farm 1.2.0

Social automation, your own SOCKS5 proxies, and several device identities from one phone.

## Social automation

- **Real provider APIs.** Mastodon (post, reply, favourite, boost), Bluesky (post, like, repost via
  the AT Protocol), Telegram (Bot API `sendMessage`), Discord webhooks, and a custom JSON endpoint for
  anything you own.
- **Scheduled actions.** Run once, or repeat every 15 minutes, hour, 6 hours or 24 hours. The
  scheduler only wakes the actions that are actually due.
- **Honest answers.** Every action shows the provider's own status and response, including
  rejections. Credentials are checked with a real call: `verify_credentials` for Mastodon,
  `createSession` for Bluesky, `getMe` for Telegram.
- **No imitation.** Providers without a usable public API are not simulated. If you own an endpoint,
  the custom provider posts to it with your bearer token.
- Tokens and app passwords are stored in this app's private storage and only sent to the provider you
  configured.

## SOCKS5 proxies

- Add as many SOCKS5 proxies as you like, with optional username and password (RFC 1928 + RFC 1929).
- Requests are tunnelled through the proxy — the handshake, auth, CONNECT and TLS all happen on the
  tunnel. A dead proxy fails the request; there is no silent fallback to a direct connection.
- HTTP proxies are supported too, with `Proxy-Authorization`.
- LIGHT and MONITOR nodes use the proxy. SESSION (WebView) nodes use the system network stack, which
  Android does not let an app override per request — that limitation is stated instead of faked.

## Device profiles

- A profile is a device identity: its own user agent, its own cookie jar and an optional proxy.
- One phone can therefore run several independent devices and logins without sharing sessions.
- Attach a profile to any node in the node editor. Profiles and proxies live in Setup.

## Install

`PhoneFarm-1.2.0.apk` for Android 8.0+, `PhoneFarmDesktop-1.2.0-windows.zip` for a 64-bit Windows
10/11 machine. The phone and the desktop agent still pair over your LAN with the token shown in the
desktop window.
