# Phone Farm 1.0.0

The first release of Phone Farm — a complete, always-on farm runtime that lives on the phone itself.

## Highlights

- **24/7 foreground runtime** with wake lock, pause/stop notification actions, boot restore and
  restore after an app update.
- **Three node types:** `LIGHT` (HTTP keep-alive, no browser engine), `SESSION` (real WebView with
  injected JavaScript) and `MONITOR` (uptime + latency probe).
- **Adaptive power governor** — throttles to a single node at a slower cadence when the phone is hot
  or the battery is low, and parks the farm at critical charge instead of draining it flat.
- **Jittered scheduling** with per-node retry backoff, concurrency cap and per-node latency history.
- **In-app updates from this page** — the app reads this repository's release feed, downloads the
  attached APK, verifies package identity and version code, then opens the system installer.
- **Strict monochrome interface** — pure black, chalk white, four greys, hairline rules, monospace
  metrics. No colour, no clutter.

## Install

Download `PhoneFarm-1.0.0.apk` below and sideload it. Android 8.0+ (API 26), arm64 or arm32.

For uninterrupted operation, open **Settings → Always on** in the app and allow battery-optimisation
exemption.

## Notes

- ~1.1 MB APK, no analytics, no accounts, no network calls other than the targets you configure and
  the update check against this repository.
- `LIGHT` nodes share one cookieless-per-node HTTP jar; `SESSION` nodes keep their cookies in the
  app's WebView profile so logins survive restarts.
- Use Phone Farm only on sites and accounts you are allowed to automate.
