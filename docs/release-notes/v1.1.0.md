# Phone Farm 1.1.0

Live screens, an AI operator, and a Windows desktop agent that the phone can drive over the LAN.

## Live tab

- **Presets with real probes.** Every preset row runs an actual HTTP request from the phone and
  shows the status code, latency and time it was checked. No seeded or demo values.
- **Screens grid.** Each tile is a PNG rendered from a real WebView at 420×720, captured on demand
  or for every node at once, and written to the app cache.
- **Watch.** Opens the node's page in a fully interactive, attached WebView.
- **Desktop agents.** Pair a Windows agent and control its farm from the phone.

## AI operator

- Works with any OpenAI-compatible endpoint — you supply endpoint, model and API key. The key is
  stored in the app's private preferences and sent only to that endpoint.
- Real tool calling: `list_status`, `add_node`, `remove_node`, `set_interval`, `set_enabled`,
  `run_node`, `set_farm`. Every call the model makes is executed against the farm and echoed in the
  transcript with its raw result.
- Optional autonomous supervisor: while the farm runs it reviews state and applies fixes at most
  once every 30 minutes.
- Without a key the screen stays in setup mode; nothing is simulated.

## Phone Farm Desktop (Windows)

- A real desktop agent with its own scheduler and HTTP runner, packaged for Windows in this release.
- Exposes a token-protected JSON API on the LAN: status, start, stop, add/remove/run node.
- The Android app is the client; the same protocol is what the Live tab's desktop cards speak.

## Install

Download `PhoneFarm-1.1.0.apk` for the phone and `PhoneFarmDesktop-1.1.0-windows.zip` for Windows.
The desktop bundle needs a 64-bit Windows 10/11 machine: unpack it and run `PhoneFarmDesktop.exe`.
It is a self-contained app image, so there is no installer and no separate JRE. `--server` runs the
same agent headless on port 8787 for a machine that only needs to farm.

Android 8.0+ is required on the phone. Keep battery optimisation disabled for 24/7 operation.
